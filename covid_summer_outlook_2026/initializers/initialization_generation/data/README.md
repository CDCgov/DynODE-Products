### Folder Content
- `fips_to_name_improved.csv`: contains USPS code and HHS region for all US states.
- `seroprevalence_50states.csv`: weekly seroprevalence data for each US state.
- `vaccination_data.csv`: daily vaccination survey data containing number of vaccinations and date of vaccination.
- `variant.csv`: estimated weekly proportion of subvariants of total.
- `weekly_hospital_*.csv`: weekly total hospitalizations for any given state. This repo only includes hospitalization for the example population.
